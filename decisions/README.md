# Cross-repository decisions

One file per decision: `YYYY-MM-DD-short-name.md`. Each file states the decision, the date, who decided,
the reasons, the options considered, and the repositories affected. Decisions are made by the maintainer;
records may be written with an AI assistant, which the record says.

Decisions taken before this repository existed are collected in
[2026-11-25-decisions-before-pena-meta.md](2026-11-25-decisions-before-pena-meta.md).
