# The website and the organization profile use MIT OR Apache-2.0

- Date: 2026-11-25
- Decided by: the maintainer. This record was written with an AI assistant.
- Affects: physical-edge-native.github.io, .github

## Decision

The repositories `physical-edge-native.github.io` and `.github` are licensed **MIT OR Apache-2.0**, like the
code repositories, with the files `LICENSE-MIT` and `LICENSE-APACHE` and the same copyright line
(`contracts.md`). This covers both code and text in those repositories.

## Reasons

Without a license file their content is "all rights reserved" by default. One rule for every repository is
simpler to keep and to check.

## Options considered

- (a) MIT OR Apache-2.0 for both. **Chosen.**
- (b) Code under MIT OR Apache-2.0 and text under CC BY 4.0.
- (c) Leave without a license.
